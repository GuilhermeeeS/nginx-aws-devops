📦 Sobre o Projeto

Este projeto demonstra um pipeline completo de DevOps, utilizando Docker para containerização, Terraform para provisionamento de infraestrutura na AWS, e NGINX como web server. Toda a infraestrutura está configurada para rodar no Free Tier da AWS.

⚙️ Arquitetura

• Container: Aplicação rodando em Docker com NGINX Alpine
• Compute: EC2 t2.micro (Free Tier)
• Rede: VPC com Security Groups configurados
• IaC: Infraestrutura gerenciada com Terraform
